This project was made as a final project or special challenge. It is not a fully developed platform, but a simple website created as part of my learning journey in web design and layouting.

### **mentalCare**
mentalCare is a simple educational website designed to raise awareness about mental health and provide a space for users to learn more about psychological well-being.
This project includes sections like homepage, services, mental health info, blog, and a contact form.
It was created mainly for learning purposes, so the design and functionality are still basic.
